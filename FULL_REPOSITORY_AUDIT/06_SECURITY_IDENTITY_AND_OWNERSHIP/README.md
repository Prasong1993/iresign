# Security, Identity, and Ownership

Purpose: collect evidence about repository/plugin identity, owners, trust boundaries, auth, permissions, secrets handling, and data ownership.

Record the exact source path/ref, observed behavior or configuration, evidence method, severity only when supported, limitations, and status. Do not copy secret values into this repository. Keep similarly named repositories and different plugin versions distinct. Source review is not a penetration test; attack testing and runtime security testing remain NOT RUN unless separately authorized and evidenced.
