# Shared Core — Reference Only

Purpose: document concepts, contracts, field definitions, shared requirements, and cross-project references that are directly supported by evidence.

This is not yet a canonical shared codebase or an approved source of truth. Keep original ownership and source references attached to every item. Where two projects disagree, record the conflict instead of choosing one silently.

Allowed at this stage: reference notes, source links, schema descriptions, provenance, and mapping proposals.

Not allowed: copying the full Project Control API database, migrating live data, merging source code, or treating a proposed common schema as approved.
